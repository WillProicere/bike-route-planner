Bike Route Planner

Roads to avoid

Click 'Add avoid zone', then click on the road on the map. Drag the red dot to move it; set the radius so the circle covers the bit of road you want to avoid.

Send to phone

Google picks its own way between stops, so the link only adds a stop on each detour (one per avoid zone or via point), placed mid-road away from junctions. Every stop is one more 'arrived' on Android Auto, so use as few as possible. Only add extras if Google strays from the blue line.
